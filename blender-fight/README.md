# Blender fight film (Oni Samurai vs Cyber Ronin)

30 s, 24 fps, 720 frames, 1920x1080. Built with headless Blender (`pip install bpy`).

- `refs/` – the 7 reference sheets
- `crops/arena/` – single-prop images for image-to-3D (Tripo / Meshy)
- `assets/glb/`, `assets/textures/` – put returned GLB files and Poly Haven textures here
- `scripts/layout.py` – arena positions in metres
- `scripts/build_arena.py` – Stage 1a blockout + clay renders (`python3 scripts/build_arena.py`)
- `previews/` – preview renders per stage
