# Oni Samurai vs Cyber Ronin (Blender film, built by scripts)

A 30-second cinematic fight in a night temple courtyard: 24 fps, frames 1001-1720, delivered at 1920x1080.
Everything is built by Python scripts that drive Blender 5.3 as a module (`pip install -r requirements.txt`);
there is no Blender window on the build machine and no GPU (Cycles on 4 CPU cores).

## Run
```bash
pip install -r film/requirements.txt          # bpy 5.3.0
python3 film/stages/s10_arena.py              # builds _data/build/arena.blend and preview stills in _data/qc/stage1
```
Scripts add the `film/` folder to `sys.path` and import `from lib import common, materials, ...`.

## Folders
- `config/project.json` frame range and render presets (`draft` 640x360, `look` 960x540, `final` 1280x720, `hero` 1920x1080)
- `config/layout.json` arena layout in metres, cameras, moon, fight marks
- `lib/` import-only modules (no work on import)
- `stages/` one re-runnable script per stage; each starts from an empty file and writes one `.blend`
- `tools/` small command-line helpers (model inspection, Poly Haven download, reference crops)
- `_data/` (not in git) `refs/` reference sheets, `inputs/` user models, `cache/` downloads, `build/` outputs, `qc/` previews

## Conventions
- Metres, Z up, **+Y = north (torii side)**, +X = east, courtyard floor at z = 0.
- A prop builder returns **one mesh object** with its origin on the ground at the centre of its footprint,
  front facing **-Y**, real-world size. It creates data in the current file only: no scene reset, no render, no save.
- Names: `PROP_*` props, `MAT_*` materials, `COL_*` collections, `LGT_*` lights, `CAM_*` cameras, `FX_*` effects.
- Repeated props are linked duplicates (`common.instance`) so they share one mesh.
- Materials come from `materials.get("MAT_...")` and must work on meshes **without UVs**
  (Object texture coordinates in metres with box projection), so any procedural mesh can use them.
- Places where a light or a hanging lantern belongs are stored on the object as custom properties holding
  local-space points: `obj["light_socket"] = [x, y, z]` or `obj["lantern_sockets"] = [[x, y, z], ...]`.
- Randomness always comes from `common.rng(seed)`; the same seed must rebuild the same result.
- Blender 5.3 API notes: engine ids `CYCLES` / `BLENDER_EEVEE`; `Material.use_nodes` is deprecated but harmless;
  noise/brick texture outputs are named `Fac` or `Factor` depending on the node (use `common.sock`);
  Principled inputs are `Emission Color`, `Emission Strength`, `Coat Weight`, `Sheen Weight`, `Subsurface Weight`;
  smooth shading with sharp edges is `common.set_smooth(obj, angle)`; no operators that need a 3D viewport.
- Previews while authoring: `render.preview_prop([obj], path, view="34"|"front"|"side"|"top", night=False)`.
